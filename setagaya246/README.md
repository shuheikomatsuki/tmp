## 作り方と精度

ネット上に公開されている GPX、Strava のルート、Garmin のコースは見つかりませんでした。そこで、大会の公式コース図と交通規制チラシの経路を OpenStreetMap の道路データに沿ってトレースしました。

- 車道部分は OSRM で道路に沿わせました。二子玉川周辺は OSM の全ての道・園路データを使って徒歩経路として計算しています。河川敷サイクリングロードと駒沢公園内の園路には、OSM のジオメトリをそのまま使っています。
- 折返し点の正確な位置は公表されていません。そのため、全体が 21.0975 km になる位置を世田谷区・狛江市境付近に置いています。
- 検算：目黒通りの上り口（玉堤）が約15.4kmになりました。報道されている「15.4km付近から目黒通りの上り」と合っています。
- 目黒通りは、交通規制チラシの「目黒通り上り ⑫等々力不動前〜⑭産能短大」のとおり、⑭産能短大（駒八通りとの交差点）まで進んでから駒八通りへ左折します。
- 道路の中心線をなぞっているため、実際の走路とは数十m程度ずれる箇所があります。とくに二子玉川駅下・兵庫島周辺と公園内の取り回しにずれがあります。公式サイトによると、今年は工事の影響で兵庫橋付近のコースが一部変わる予定です。
- 時計の距離表示は、実際のコースの距離表示とずれることがあります。

## 主なアプリへの取り込み方法

- **Garmin Connect**：Web版の「トレーニングと計画 → コース → インポート」で GPX を選び、保存してデバイスに送信します。
- **Strava**：Web版の「マイルート → インポート（GPX）」から取り込みます。
- **COROS**：アプリの「ルート → 右上＋ → インポート」で GPX を選びます。
- **Suunto**：アプリの「マップ → ルート → インポート」から取り込みます。
- **Google マイマップ**：「インポート」で KML を選びます。
